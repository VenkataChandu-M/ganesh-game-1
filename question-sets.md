# Bappa's Test — Question Sets (4 sets × 20 trials)

Each set is a complete, self-contained sequence. When a player fails, the game
switches to the next set (cycling back to Set 1 after Set 4), so no retry ever
shows the exact same 20 trials in the same order with the same details.

Format per trial: `instruction | visual | correct action | note`

## How the rotation works in-game
- Attempt 1 → Set 1
- Attempt 2 (after a fail) → Set 2
- Attempt 3 → Set 3
- Attempt 4 → Set 4
- Attempt 5 → back to Set 1, but with the pool-based variants still reshuffled, so even repeats of a set aren't identical
