# Bappa's Test — Question Sets (4 sets × 20 trials)

Each set is a complete, self-contained sequence themed around Lord Ganesh's mythology.
When a player fails, the game switches to the next set (cycling back to Set 1 after Set 4),
so no retry ever shows the exact same 20 trials in the same order.

Format per trial: `instruction | visual | correct action | ganesh fact`

---

## How the rotation works in-game
- Attempt 1 → Set 1 ("The Birth of Ganapati")
- Attempt 2 (after a fail) → Set 2 ("The Names of Ganapati")
- Attempt 3 → Set 3 ("The Stories of Ganapati")
- Attempt 4 → Set 4 ("The Symbols of Ganapati")
- Attempt 5 → back to Set 1, but with the pool-based variants still reshuffled
